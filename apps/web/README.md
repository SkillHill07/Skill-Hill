# @skillcontest/web

Next.js App Router frontend — user-facing contest platform.

## Skills

| Skill | Used for |
|---|---|
| `frontend-design` | UI direction and layout |
| `frontend-dev` | Building pages and components |
| `design-taste-frontend` | Preventing templated / sloppy UI |
| `frontend-design-review` | Reviewing UI changes |
| `performance` | Core Web Vitals, bundle optimization |
| `accessibility` | WCAG compliance, screen readers |
| `react-best-practices` | React patterns, component design |
| `react-patterns` | Hooks, composition, performance |
| `tanstack-query-expert` | Server data fetching hooks |
| `nextjs-app-router-patterns` | Server Components, App Router patterns |
| `nextjs-best-practices` | Next.js conventions |
| `tailwind-patterns` | Tailwind v4 usage |
| `ponytail` | Debt tracking |

## Quick start

```bash
pnpm dev           # next dev :3000
pnpm build         # next build
pnpm typecheck     # tsc --noEmit
pnpm lint          # eslint src --ext ts,tsx
```
